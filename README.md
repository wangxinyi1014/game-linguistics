# 游戏 × 语言学 · 无声片盘

**游戏 × 语言学（第二语言习得）** —— 一个分级词汇的英语侦探游戏。你在一间伦敦配音棚里查一桩案子：某集英语配音的母带被抹成了空白。四个嫌疑人，六条证据，你到九点为止。

在线试玩：**https://wangxinyi1014.github.io/game-linguistics/**

单文件 HTML，双击即可玩，不需要联网、不需要安装。词条按 CEFR 分级（A2 / B1 / B2 / C1），可切换级别重读。

---

## 一、为什么是侦探，而不是背单词 App

词汇学习的常见失败模式，是"记住了，但读的时候认不出来"。原因不在记忆强度，而在**没有后果**：读错一个词，什么都不会发生，所以大脑不把它当回事。

侦探故事天生提供后果。一句证词里有一个词没读准，推理就会走偏；指认错了，案子就结不了。这个游戏把这条因果链接死：

> **理解就是取证。**
> 每个人物身上挂一条线索，而线索只在你说对某个词的意思之后才会出现。

这不是在阅读之外加一层测验，而是让阅读理解**变成**游戏的推进器。真正被考的不是记忆力，是"在上下文里判断一个词到底什么意思"的能力——这也是阅读中最容易自我欺骗的一环（"大概懂"）。

## 二、分级词汇怎么做的

正文只写一遍，难度用**词级标注 + 显示门槛**来调，而不是写四个版本的故事。

- 词表（`WORDS`，本 demo 65 条）给每个词标 CEFR 级别、音标、中文、英文释义。
- 玩家选一个级别（A2 / B1 / B2）。**只有高于当前级别的词会被加虚线下划线**：A2 模式下几乎每个实词都有标注，B2 模式下只剩 C1 词。
- 点任意标注词即弹释义，同时自动进生词本（存在 localStorage，关掉浏览器也在）。
- 选 A2 时，每场开头额外给一个"这一段在说什么"的英文简版 + 中文一句话，作为低级别读者的降落伞。

这样做的代价是词表覆盖率有限（只标注词表内的词），好处是同一份文本可以服务四个水平，而且改起来只改词表，不动故事。

## 三、一场的结构

| 环节 | 作用 |
|---|---|
| 场景正文 | 4 场，约 600 词，B1 基线写，长句与术语留给 B2/C1 |
| 语言关卡 | 1 个关键对话词，三选一（第四场是四选一）。答错给提示、可重试；答对才发线索 |
| 场景快测 | 每场 2 题：词义、搭配、语域（哪句是模糊语、哪个词最正式） |
| 证据板 | 6 条线索，左侧实时更新 |
| 指认 | 选 1 个嫌疑人 + 2 条证据，组合不对会给针对性反馈，不是简单判错 |
| 词汇报告 | 生词本按级别排序，统计查词次数与理解题正确率，可导出 .txt |

## 四、谜题是"公平"的：答案在语言里

案子不靠指纹，靠**语体**。四个嫌疑人各有稳定的说话方式，写在指认页的档案卡上：

- **Mara**（对白改编）：祈使句，短，不给余地，没有模糊语。
- **Del**（混音师）：全程 right / yeah / I mean，指控从不说完。
- **Ivy**（场务）：反义疑问句 yeah? innit?，俚语。
- **Rowan**（语言工程师）：model / inference / pipeline。

母带被抹掉后，磁头处残存十一个词：`SAY IT SLOWER. THEY'LL NEVER HEAR THE DIFFERENCE.`

判断依据不在内容，在句法：没有主语、没有 please、没有模糊语、没有术语——这是祈使句。而且这句话，Mara 在第一场就当着你的面说过一次。玩家如果只关心"谁可疑"，会漏掉它；如果关心"这句话是谁会说的"，案子就破了。

这就是这个 demo 想主张的东西：**在语言学习里，语体意识（register awareness）比词汇量更接近"读懂了"。**

## 五、已实现 / 未实现

已实现：三级切换、点词查义、生词本持久化与导出、4 场线性推进、4 个语言关卡、6 条证据、指认与针对性反馈、词汇报告、移动端布局。

未实现（下一步可做）：

- 词表只覆盖正文 65 个词头，不是全文标注；扩词表是主要工作量。
- 没有间隔重复：生词本只导出，不排复习队列。
- 没有音频：发音只有音标，没有 TTS。
- 没有分支：4 场是线性顺序，重玩只有"升一级重读"。
- 没有多语言界面（正文英文，提示中文）。

## 六、代码

单文件 `index.html`，零依赖，原生 JS。数据在文件顶部，三块：

```js
const WORDS = { "wipe": {l:"B2", ipa:"/waɪp/", zh:"抹掉、消除（录音）", en:"to erase all the sound..."}, ... }
const CLUES = [ {id:"c1", short:"…", body:"…"}, ... ]
const SCENES = [ {id:"booth", head:"I · THE BOOTH", beats:[…], challenge:{…}, quiz:[…]}, ... ]
```

- `beats` 支持四种：`nar` 叙述、`say` 对白、`log` 等宽字体的记录/转写、`stmt` 直接发一条线索。
- `challenge` 的 `clue` 字段指向 `CLUES` 的 id，答对即入证据板。
- 词形还原用后缀规则处理（`-s / -es / -ed / -ing`），所以词表里只写原形。
- 封面图 base64 内嵌，整份产物就是一个文件。

### 加一场戏

在 `SCENES` 里追加一个对象，照抄现有字段；新词写进 `WORDS` 并标级别；线索写进 `CLUES` 并在 `challenge.clue` 里引用。不需要改任何渲染代码。
